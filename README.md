## 👨‍💻 About Me

I'm a **MERN Stack Developer** and a **BS Computer Science** student at Virtual University of Pakistan, focused on building full-stack web applications from the ground up — database design, backend logic, and the frontend that connects to it.

I learned the MERN stack through **Saylani Mass IT Training (SMIT)**, where I completed a full-stack web development course (Feb 2025 – April 2026), building a solid foundation in **React, Node.js, Express, and database design**.

I don't have formal industry/internship experience yet — but I make up for it by building complete, production-style projects on my own: designing the database, writing the backend from scratch, handling authentication properly, and connecting it all to a real frontend. I treat every project like it has to work in production, not just run on my machine.

- 🎓 Trained at **Saylani Mass IT Training** — full MERN stack course
- 🏗️ Comfortable across the stack: **React/Next.js** on the frontend, **Node.js/Express** on the backend, **PostgreSQL + Prisma** for data
- 🔐 Have hands-on experience with real auth systems (JWT, refresh tokens, OTP-based flows) — not just tutorials
- 🎯 Looking for an **internship or junior developer role** to apply what I've built on my own to a real team and real users
- 💡 I believe in **consistency over speed** — building strong fundamentals first
